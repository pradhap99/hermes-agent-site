Hermes Agent

Hermes Agent is a personal AI assistant run by Pradhap M. It connects to the owner's Google account (Gmail, Calendar, Drive, Sheets and Docs) so the assistant can read, organise and act on the owner's own information when asked.

It is built on the open-source Hermes Agent project and is operated independently for personal use.
